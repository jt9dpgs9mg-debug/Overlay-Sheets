Overlay sheets from a plan set

Open a PDF drawing set to compare disciplines. Sheets line up on their column and row grids, so an HVAC plan lands on the architectural roof plan without manual fiddling.

  1. Open or drop a plan set PDF. The sheet list builds from the title blocks and sheet index.
  2. Click a sheet to make it the base, then tick other sheets to overlay them.
  3. Adjust color, transparency, crop and position, then export a PDF for Bluebeam.
